১ অধ্যায় ১: মৌলিক ধারণা

এই অধ্যায়ে আমরা গণিতের মৌলিক ধারণাগুলো নিয়ে আলোচনা করব। সংখ্যা, চলক, ধ্রুবক এবং সমীকরণের সাথে পরিচিত হব।

ax² + bx + c = 0

উপরের সমীকরণটি একটি দ্বিঘাত সমীকরণ, যেখানে a, b, c হলো ধ্রুবক এবং x হলো চলক।

উদাহরণ ১: x² - 5x + 6 = 0 সমীকরণটি সমাধান করো।
সমাধান: (x - 2)(x - 3) = 0, অতএব x = 2 অথবা x = 3।
পৃষ্ঠা ১ / ৩২০
২ অধ্যায় ২: সমীকরণ সমাধান

সমীকরণ সমাধানের বিভিন্ন পদ্ধতি রয়েছে। এর মধ্যে উল্লেখযোগ্য হলো প্রতিস্থাপন পদ্ধতি, অপসারণ পদ্ধতি এবং গ্রাফিক্যাল পদ্ধতি।

দ্বিঘাত সমীকরণের মূল নির্ণয়ে শ্রীধর আচার্যের সূত্র ব্যবহার করা হয়:

x = (-b ± √(b² - 4ac)) / 2a
উদাহরণ ২: 2x² + 5x - 3 = 0 সমীকরণটি সমাধান করো।
এখানে a = 2, b = 5, c = -3। সূত্রে বসিয়ে পাই: x = 1/2 অথবা x = -3।
পৃষ্ঠা ২ / ৩২০
৩ অধ্যায় ৩: অনুশীলনী

নিচের প্রশ্নগুলো সমাধান করে নিজের দক্ষতা যাচাই করো। প্রতিটি প্রশ্নের উত্তর অধ্যায়ের শেষে দেওয়া আছে।

প্রশ্ন ১: x² - 7x + 12 = 0 সমীকরণটি সমাধান করো।

প্রশ্ন ২: 3x² + 2x - 8 = 0 সমীকরণের মূল নির্ণয় করো।

প্রশ্ন ৩: যদি α এবং β হয় x² - 4x + 3 = 0 এর মূল, তবে α + β এবং αβ এর মান কত?

বিস্তারিত সমাধান বইটির পরবর্তী পৃষ্ঠাগুলোতে পাওয়া যাবে...
